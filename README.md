# Chintala Mahindra — 3D room portfolio

A Next.js portfolio with a scroll-driven 3D room built with Three.js and React Three Fiber.

## Run locally

npm install
npm run dev

Then open http://localhost:3000

## Deploy

Import this repository into Vercel and use the default Next.js settings.

## Contact form

Set NEXT_PUBLIC_FORMSPREE_ID in Vercel environment variables if a Formspree form is needed. Without it, the portfolio keeps the direct email contact flow.

## Personal data

Edit lib/site.ts for personal links and project URLs.
